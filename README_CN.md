# DSH 减重记录面板

**English:** [README.md](./README.md)

给 DSH 加一个侧边栏面板：每天用半分钟记下体重、腰围、步数和训练量，面板自己算趋势、离目标还有多远、按现在的速度大概哪天到。

数据只存在你自己的浏览器里，不联网、不上传、不读聊天记录。

---

## 写在前面

> 这段是作者自述，只想看怎么用的话可以直接跳到下一节。

这个插件是为我自己最近想施行的减重计划让 DeepSeek 帮我做的，目前只有数据录入。

我是根据体脂秤显示的数据直接填上去的，因为这些数据比较割裂。我之前用的是蚂蚁阿福，虽然也很好用，但是我的体脂秤连接不上就很尴尬。

而且之前看到很多人让 GPT 或者其他 AI 帮自己制定相关的计划，所以做了这个小插件，方便录入之后让 agent 读取你的身体数据，从而量身定制相关方案，起到一个类似健身私教的作用（虽然它不会纠正你的动作有多规范）。

其实大家最苦恼的问题我感觉是有关于摄入热量的计算。关于这一点我还没想好，因为图片识别热量这个东西很抽象，而且没有人去学校食堂吃饭会随身带一个小电子秤吧。。

后续我再继续完善一下相关功能。

## 一、为什么看周均值，而不是单日体重

减重时最容易做的两件错事：**被单日体重吓到**、**只记体重不看腰围**。

单日体重受水分、盐分、排便、睡眠影响，浮动 1 kg 很正常；真正要看的是 7 天均值的变化方向。而这个面板就是围绕「周均值 + 腰围 + 完成度」设计的，不是围绕单日数字。

## 二、安装

### 方式 A：用 DSH 自带的插件管理（推荐）

在任意 DSH 会话里让 Agent 执行：

```
plugin_manager({ action: 'install_bundle', target: '/你的路径/dsh-weight-panel' })
```

装完侧边栏底部会出现一个**折线图图标**（排在 Plugins、Schedules 之后）。

### 方式 B：手动装（等价于 A 干的事）

1. 把整个包放到 profile 的 `node_modules/dsh-weight-panel`（或用 `file:` / `link:` 依赖指向它）
2. 在 profile 的 `package.json` 里，把 `"dsh-weight-panel"` 加进 `dsh.profile.bundles` 数组
3. 重启 DSH

> 本包零依赖、无构建步骤，`lib/` 里的文件就是最终运行的代码。装的时候不需要 `npm install` 拉任何东西。

---

## 三、第一次打开：只填「档案」

点侧边栏图标，中间列会打开面板。最上面是**档案**，五项，填一次就行，之后随时可改：

| 字段 | 填什么 | 备注 |
|---|---|---|
| 身高 (cm) | 例如 `180` | 用来算 BMI |
| 目标体重 (kg) | 例如 `88` | 「距目标」需要一个明确数字 |
| 目标日期 | 例如 `2027-02-16` | 只作参照，不参与计算 |
| 每日热量目标 (kcal) | 例如 `2000` | 你自己定的口径，面板不替你判断 |
| 每日蛋白目标 (g) | 例如 `150` | 同上 |

**这五项面板不会给你建议**。数值从哪来取决于你自己的方案；面板只负责记录和计算，不做判断。

---

## 四、每天怎么用（约 30 秒）

中间是**录入**区。日期默认今天。

| 字段 | 多久填一次 | 怎么量 |
|---|---|---|
| 体重 (kg) | 每天 | 晨起、空腹、排尿后、同一台秤。这台秤的条件固定比数值准确更重要 |
| 腰围 (cm) | **每周一次即可** | 肚脐水平绕一圈，正常呼气末量，别吸肚子 |
| 步数 | 每天 | 手机健康 App 抄一下 |
| 力量 (分钟) | 有练才填 | 当天做力量/自重训练的分钟数，20 分钟按一次算 |
| 快走 (分钟) | 有走才填 | 强度：能说话、不能唱歌 |

**只有体重是必须的**，其余空着不影响保存和使用。填完点「保存」。

想补记或改以前某天：把日期改成那天，面板会自动把已存的内容带出来；改完保存即覆盖。

## 五、概览区每个数字怎么读

| 显示 | 含义 | 怎么用 |
|---|---|---|
| 最近体重 | 最后一条有体重的记录 | 看趋势，不看单日 |
| BMI | 体重 ÷ 身高² | 粗筛指标，肌肉量大的人会偏高，别当唯一标准 |
| 距目标 | 当前体重 − 目标体重 | 负数说明已经低于目标 |
| 近 7 天平均 | 最近 7 天的体重均值 | **这是你真正该看的数** |
| 较前 7 天 | 本周均值减上周均值 | 下降 0.3～0.8 算正常；连续两周不动就该调整 |
| 力量 x / 60 min | 本周力量训练累计 ÷ 内置周目标 60 分钟 | 保肌指标，别掉 |
| 快走 x / 100 min | 本周快走累计 ÷ 内置周目标 100 分钟 | 赤字与心肺 |
| 日均步数 x / 8000 | 本周有步数记录的那些天的平均 | 日常活动量 |
| 按趋势预计达标 | 用近 20 天有体重的记录做最小二乘回归，外推到目标体重 | 样本少于 4 条、或趋势不降时显示「数据不足」/「—」 |

分母 60 / 100 / 8000 是写死在界面里的默认值，想改成自己的口径，搜索 `lib/client.js` 里的 `/ 60 min`、`/ 100 min`、`/ 8000` 三处字符串即可。

## 七、「复制给 DSH」是干什么用的

面板数据存在**浏览器 localStorage** 里，Agent 读不到磁盘上的文件，所以默认情况下你和 Agent 对话时它是看不见这些数据的。

点一下「复制给 DSH」，会把档案摘要、周均值、本周完成度、预计达标日和最近 14 条明细拼成一段文本放进剪贴板。**粘贴到对话里**，Agent 就能基于真实数据给调整建议。

这是刻意设计：数据不自动外流，只在你自己复制粘贴时才交出去。

---

## 八、数据、隐私和重置

- 存储位置：浏览器 `localStorage`，键名 `dsh.weight-panel.v1`
- 不发起任何网络请求，不发遥测，不读会话内容，不写文件
- 换浏览器、清站点数据、隐私模式关闭窗口 —— 数据都会丢失，**建议每周复制一次**留档
- 彻底重置：打开浏览器控制台执行
  ```js
  localStorage.removeItem('dsh.weight-panel.v1')
  ```
  然后刷新页面

## 九、常见问题

**侧边栏没有图标**
先刷新页面（`Cmd+R` / `Ctrl+R`）。仍然没有就重启 DSH —— 客户端 bundle 是启动时加载的。

**面板打开是空白，或控制台报 `slot entry crashed in 'main'`**
说明渲染时抛错了，把控制台报错发给我／提交 issue。

**填完刷新就没了**
浏览器处于隐私模式，或清过站点数据，或禁用了 localStorage。

**体重一天涨了 1 kg**
正常。水分、盐分、排便、糖原都会影响，看 7 天均值。

**改了目标体重，之前的记录会变吗**
不会。记录是原始数据，「距目标」「预计达标」会按新目标重算。

**能多设备同步吗**
不能。这是本地存储的取舍：换来的是数据不出本机。

## 十、它不做什么

- 不改模型、不调提示词、不读聊天记录
- 不联网、不上传
- 不给饮食或训练建议 —— 那是和你对话的 Agent 的事，面板只负责记录与计算
- 不替你做医学判断

## 十一、目录结构

```
lib/client.js        整个界面与计算（浏览器侧，懒加载 CJS 模块）
lib/index.js         Host 侧空壳，只为让 bundle 有 Host 行
cordis.patch.yml     bundle 挂载声明（插入 weight-panel 这一行）
locale/{en,zh}.json  插件管理器里显示的标题与描述
icon.svg             插件图标
check.mjs            自检脚本：桩渲染真实组件并断言数值
package.json         包清单（dsh.bundle.patch + dsh.client）
```

挂载点：`sidebar.panellist`（图标，id `weight-panel`）与 `main`（面板，key `weight-panel`）。这两个标识必须一致，侧边栏靠 id 找到对应的主面板。

---

## 十二、开发与自检

```bash
node --check lib/client.js
npm run check     # 等价于 node check.mjs
```

`check.mjs` 不依赖任何第三方库：它用假的 `React` 和 `localStorage` 渲染真实组件，然后断言输出的数值（BMI、周均值、差值、本周累计、预计达标日、空状态）。
